# NA-Tool (Netzanträge Tool)

Offline-Tool zur Erstellung von VDE-AR-N-4110-Netzanschlussunterlagen
(Messkonzept, E.1, E.8, Vollmacht, Datenblätter) aus Motor-/Trafo-Auswahl.

## Nutzung
1. `index.html` herunterladen.
2. Per Doppelklick im Browser öffnen — läuft komplett offline, keine Installation.
3. Projektdaten eingeben, Motoren/Trafos wählen, Dokumente als ZIP erzeugen.

## Hinweise
- Interne, vertrauliche Vorlage (enthält Hersteller-Datenblätter und Netzbetreiber-Vorlagen). **Nicht öffentlich weitergeben.**
- Repository bewusst **privat** — Zugriff nur für eingeladene Personen.
- Dateigröße ~93 MB (Datenblätter fest eingebettet).
